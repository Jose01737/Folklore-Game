# Cool ideas to take this further

## Core hooks
- **Lore is the weapon.** Never tell the player the weakness. Make notes contradict each other (rumor vs elder vs outsider) so players have to judge sources.
- **Real languages.** Voice the clues in the local language with subtitles. Whispers should be in-language and not translated.
- **Gaze rules per culture.** Some spirits are stopped by looking, some by NOT looking, some by silence, some by naming them correctly.
- **Wrong cure, worse night.** A wrong item should change the creature, not just anger it (the Aswang becomes aggressive, the Rusalka drops her song).
- **Sacred objects can be misused.** Using an ofuda wrong has consequences. It teaches respect.

## Systems
- **Hub: The Archive.** A library between chapters where you pin clues on a corkboard, compare monsters and unlock a bestiary.
- **Cross-culture chapters.** Late game: two entities in one level (Nuckelavee plus Rusalka) where the right answers conflict.
- **Time of night / season.** Midsummer for Rusalka, winter for Wendigo, new moon for Aswang. Weather affects AI.
- **Sound design as gameplay.** Directional audio from the lure sounds; headphones recommended. Mic input (optional) for whispering through quiet sections.
- **Companion NPC.** A local guide who knows part of the lore but is unreliable.
- **Permanent consequences.** Skip a ritual, and a later chapter has a harder variant of that entity.
- **Daily Folklore.** A seeded daily run with a random creature and random item pool, plus a leaderboard.

## Urban legends mode
Short 10-minute levels based on modern legends: haunted elevator rituals, the vanishing hitchhiker, late-night convenience store, abandoned subway line.

## Art direction
- Each region gets its own **art style and color script** (ukiyo-e inspired Japan, papel picado Mexico, wayang shadow-puppet Malaysia, woodcut Slavic).
- Keep monsters mostly hidden. Reveal only when the player has learned enough lore. Better lore = clearer vision.

## Steam features
- Achievements per creature, plus a "no item wasted" run.
- Steam Cloud saves, Steam Deck verified (controller support: gamepad actions are easy to add in `game_state.gd`).
- Workshop: let players write their own creature JSON. The data-driven design is already built for it.
